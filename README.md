# rooftop-segmenter

A segmentation CNN written from scratch for buildings and rooftops in aerial imagery. The geospatial starter project; it feeds rooftop solar in satellite-change.

## Phases

1. **Data:** aerial image tiles with building footprint labels (licences checked).
2. **Model:** a U-Net-style network built and trained from scratch on the Mac.
3. **Evaluate:** IoU on held-out areas, failure cases, write-up.
